# Private Investigator Casablanca

## 📌 Project Overview

**Private Investigator Casablanca** is a digital platform designed to present private investigation services in Casablanca, Morocco. The project aims to provide clients with a professional, confidential, and accessible way to learn about investigation services and submit requests for assistance.

The platform focuses on discretion, professionalism, data protection, and clear communication between clients and the investigation agency.

## 🎯 Objectives

- Present private investigation services professionally.
- Allow clients to contact the agency securely.
- Enable clients to submit investigation requests.
- Manage client inquiries and investigation cases.
- Protect confidential client information.
- Provide a responsive interface for desktop, tablet, and mobile devices.

## 🕵️ Main Features

### 1. Home Page
- Presentation of the agency.
- Overview of available services.
- Professional design highlighting confidentiality and trust.
- Contact information and calls to action.

### 2. Investigation Services
Potential services may include:
- Background and information verification, where legally permitted.
- Business and commercial investigations.
- Fraud-related inquiries.
- Missing-person inquiries, subject to applicable law.
- Evidence documentation and factual reporting within lawful limits.

### 3. Client Contact
- Contact form.
- Secure inquiry submission.
- Appointment request.
- Clear information about confidentiality and data handling.

### 4. Case Management
For an authorized administrator:
- Register client inquiries.
- Assign case reference numbers.
- Track case status.
- Store relevant documents securely.
- Manage access according to user permissions.

### 5. Security and Privacy
- Protect personal and confidential information.
- Restrict access to authorized users.
- Use secure connections (HTTPS).
- Apply appropriate data-retention and deletion policies.
- Respect Moroccan law and applicable personal-data protection requirements.

## 🚀 Installation

### Prerequisites
- Node.js and npm, if using the proposed backend.
- MongoDB or a configured MongoDB Atlas database.
- Git, if version control is used.

### Steps

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Enter the project directory:

   ```bash
   cd private-investigator-casablanca
   ```

3. Install backend dependencies:

   ```bash
   cd backend
   npm install
   ```

4. Configure environment variables using `.env.example` as a template.

5. Start the backend using the script defined in `package.json`.

6. Start the frontend according to its development setup.

**Important:** The commands above are a template. They must be adapted to the actual project structure and scripts.

## ⚖️ Legal and Ethical Considerations

The platform is intended for lawful investigation activities only. All services must respect privacy, personal-data protection, and applicable Moroccan legislation. The project must not facilitate unauthorized surveillance, unlawful access to accounts or devices, harassment, or the collection of private information without a valid legal basis.
